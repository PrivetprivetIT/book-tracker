# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с сохранением данных в JSON.

## Как запустить

```bash
python main.py
```

## Возможности
+ Добавление книги (автор, название, оценка 1–5, дата прочтения)
+ Просмотр всех книг
+ Средняя оценка по всем книгам
+ Статистика по авторам (количество книг)
+ Удаление книги

## Пример работы

1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
